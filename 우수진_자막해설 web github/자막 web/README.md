# CBoE · SDH 자막 검수 화면 (웹)

`DESIGN.md` 7절(검수 화면 3.1–3.5)과 5.7·5.9 규칙을 브라우저 한 장으로 옮긴 화면이에요.
점 격자 캔버스 위 프레임처럼 보이고, 시연을 켜면 화면이 스스로 눌리고 옮겨지며, 설명은 화면 아래 한 줄로 떠요.

```
cboe-web/
├─ index.html           ← 메인: 자막해설 소개 페이지
├─ studio.html          ← 서브: 영상 위 자막 + 검수 화면 (샘플 내장)
├─ serve.py             ← 로컬 서버 (영상 건너뛰기용 Range 지원)
├─ cboe_colab.ipynb     ← Colab 실행
├─ work/sample/         ← DESIGN.md 3절 형식 샘플 작업 폴더
│   project.json  dialogue.json  items.json  cuts.json
└─ media/               ← 영상 넣는 곳
```

## 실행

| 방법 | 하는 법 |
|---|---|
| 그냥 열기 | `index.html`(소개) → ‘검수 화면 열기’, 또는 `studio.html` 바로 열기 → **작업 폴더** 버튼으로 CBoE 작업 폴더 선택(또는 폴더째 드래그) → 영상 드래그 |
| VS Code | `python serve.py --work work/sample --video media/movie.mp4` |
| Colab | `cboe_colab.ipynb` 위에서부터 실행 |
| 주소 | `studio.html?work=<작업폴더>&video=<영상>` · `?subs=<srt/vtt>` · `?demo=0`(시연 끄기) |

## 읽는 파일 (DESIGN.md 2·3절 그대로)

| 파일 | 쓰임 |
|---|---|
| `items.json` | 후보 목록·근거·추천·에이전트 기록 |
| `dialogue.json` | 대사 칸 · 어절 시각(칸 나누기에 씀) |
| `cuts.json` | 장면 전환 눈금 · 음악/끝 조정 |
| `project.json` | 제목 · fps |
| `review.json` | (있으면) 작가 결정 이어서 |
| `draft.json` | `dialogue.json` 이 없을 때만 — 그대로 보여 주고 재배치는 안 함 |

SRT/VTT 를 바로 열어도 돼요: `[소리]` → 효과음, `♬` → 음악, `(이름)` → 화자, `- ` → 두 출처로 나눠 읽어요.

**내보내는 것:** SRT · VTT (`check` 와 제외는 빠짐), `review.json` (파이프라인 작업 폴더에 넣으면 이어서 씀).

## 자막 표기 · 위치

- 위치는 **하단 중앙 고정**이에요(바닥에서 7.5%, 폭 88%). 종류가 달라도 자리는 움직이지 않아요.
- `[따릉]` `[쿵, 책 떨어지는 소리]` · `♬ 무서운 음악` · `(지아) 같이 가요.`
- 두 출처는 하이픈 두 줄로 쓰고 왼쪽 정렬해요: `- 조금만 더 볼게요.` / `- [딸깍]`
- 화면에서만 소리·음악·화자 색을 살짝 구분해요(‘색 구분’으로 끔). 내보낸 파일은 글자만 들어가요.

## 배치 (5.9) — 브라우저 버전

고칠 때마다 다시 계산해요. 16자/줄(한글 1 · 라틴·공백·숫자 0.5), 2줄, 14자/초, 5/6–7초, 2프레임 간격.
빈틈에 따로 한 칸 → 대사 시작 0.5초 안이면 하이픈 두 줄(그 화자의 소리면 한 줄) → 대사 중간이면 어절 경계에서 나눔 → 짧은 문구 → 0.5초 안 빈틈으로 옮김 → **배치 확인 필요**.
대사 글은 자동으로 바꾸지 않고, 소리를 자동으로 빼지 않아요. 서버(`placement.py`, Kiwi 줄바꿈)와 줄바꿈 위치가 조금 다를 수 있어요 — 최종본은 파이프라인 `export.py` 기준.
