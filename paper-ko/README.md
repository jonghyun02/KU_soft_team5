# paper-ko — 논문 PDF 구조 그대로 한국어 번역하기

논문 한 줄씩 복붙하면서 번역하려니 귀찮아서 만들었습니다. 그림, 구조 다 그대로 두고 영어 글자만 한글로 바꿔요.

## 쓰는 법

- build_exe.bat를 누르면 exe 만들어집니다.
- exe누르고 클로드 연동하고 쓰시면 됩니다.
- 결과물: 1. 번역만, 2. 원본 번역본 붙어있는거

## 번역 엔진

- `claude` (기본): 이 PC 에 로그인된 Claude Code 불러서 씁니다. 추가로 돈 안나가고 구독 한도 내에서만 해요.
- `google`: 클로드 없을 때 무료용

## 한계

- PDF가 그림이면 안 됩니다. 글자만 번역해줘요.
